# GoolBot - Мониторинг футбольных коэффициентов

Бот для мониторинга футбольных матчей и поиска сигналов на "Тотал Больше" (Over) на основе прогрузки коэффициентов.

## Архитектура

```
gool_bot/
├── config/          # Конфигурация приложения
├── db/              # Работа с базой данных (SQLite)
├── api_client/      # Клиенты для API (Infersports, Highlightly)
├── brain/           # Анализ сигналов
├── notifier/        # Уведомления Telegram
└── main.py          # Точка входа
```

## Источники данных

1. **Infersports** (основной) - сканирование матчей и коэффициентов
2. **Highlightly** (подтверждение) - анализ H2H, формы команд, средних голов

## Логика работы

### Пороги срабатывания:
- **3-7%**: Шум (игнорировать)
- **8-14%**: Умные деньги (логировать)
- **15%+**: СИГНАЛ (отправлять в Telegram)
- **25%+**: Паника/Аномалия (максимальный приоритет)

### Расписание:
- **00:00** - Ночной скан (получение матчей на 48 часов)
- **Каждые 5 мин** - Мониторинг коэффициентов
- **23:00** - Очистка БД от старых матчей

## Установка

```bash
# Установка зависимостей
pip install aiohttp

# Настройка переменных окружения
export TELEGRAM_BOT_TOKEN="your_bot_token"
export TELEGRAM_CHAT_ID="your_chat_id"

# Запуск бота
python -m gool_bot.main
```

## Конфигурация

Переменные окружения (опционально):
- `TELEGRAM_BOT_TOKEN` - токен Telegram бота
- `TELEGRAM_CHAT_ID` - ID чата для уведомлений
- `DATABASE_PATH` - путь к файлу БД (по умолчанию: gool_bot.db)
- `INFERSPORTS_API_KEY` - ключ API Infersports
- `HIGHLIGHTLY_API_KEY` - ключ API Highlightly

## Важные особенности

- Если сигнал от Infersports сильный (>15%), но Highlightly не отвечает или лимит исчерпан — сигнал ВСЕ РАВНО отправляется пользователю
- Бот сохраняет результаты матчей для ведения статистики успешности сигналов
- Все значимые события логируются в базу данных и файл `gool_bot.log`

## Структура базы данных

- `matches` - матчи с начальными и текущими коэффициентами
- `signals` - история всех сигналов
- `match_results` - результаты матчей (для статистики)
- `logs` - логи событий
