# GOOL AI 2.0 — LIVE football analytics

GOOL работает только по LIVE-матчам и отправляет actionable-сигналы, когда игровая статистика, модель и доступный рынок одновременно проходят фильтры риска/value.

## Источники данных

**Источник истины — Flashscore/LSApp.** Из него GOOL получает список LIVE-матчей, счёт/минуту, статистику, историю формы/H2H и текущие LIVE-линии. Рынок может стать actionable только если точная линия существует в Flashscore/LSApp в момент оценки.

Дополнительные источники используются только как подтверждение:

- **Kambi/BetRivers** — подтверждение той же LIVE-линии и движение цены; не создаёт отсутствующий рынок и не заменяет цену Flashscore.
- **SportsGameOdds** — опциональный дополнительный bookmaker/opening context для уже существующего рынка; не создаёт сигнал.
- **xG/xGoT consensus, league profile, recent form/H2H и prematch math** — аналитический контекст. Они могут усиливать или ослаблять оценку, но не создают сигнал без LIVE-подтверждения.

Bovada отключена и не используется в production-логике.

## Основные стратегии

- **GOOL CORE** — основной multi-market LIVE engine. Новые входы: с 10-й минуты, пауза 46–54', базовое окно до 75'. После гола возможен отдельный re-entry при новом подтверждении.
- **FIRST_HALF_GOAL** — собирает динамику с начала матча, сигнал возможен примерно 15–25'. Требуется точный Flashscore/LSApp рынок первого тайма.
- **SECOND_HALF_OVER15** — решение в перерыве по полной статистике первого тайма. Требуется точный Flashscore/LSApp рынок ТБ1.5 второго тайма.

## Risk / value

- один открытый exposure на матч;
- максимум два реальных входа на матч;
- CORE: минимум 5 п.п. value edge;
- re-entry: минимум 7 п.п.;
- auxiliary strategies: минимум 6 п.п.;
- внешний источник не может обойти эти фильтры.

## Учёт результата

GOOL хранит `primary` выбранной ставки и рассчитывает результат по самому рынку, а не по факту следующего гола. Для CORE поддерживаются market-aware settlement, push/азиатские четвертные линии, `pnl_units`, ROI и CLV. `/report` показывает текущую статистику, `/analysis` — накопленный анализ по рынку, минуте, MASTER/strategy score, edge и CLV.

## Production

Точка входа: `gool_bot/main.py`. Бот работает циклически 24/7, Telegram polling/heartbeat/goal watcher запускаются отдельными задачами. Базовая проверка Python-кода выполняется GitHub Actions workflow `GOOL Python Audit`.

Секреты и API-токены не должны храниться в репозитории. Используйте переменные окружения хостинга (`TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` и ключи подключённых опциональных провайдеров).
